# 🧠 Proyecto: Detección de Objetos con ML5.js y Teachable Machine

## 📘 Descripción general
Este proyecto aplica **inteligencia artificial con ML5.js y p5.js** en tres actividades prácticas, donde se desarrollaron diferentes aplicaciones para el **reconocimiento y detección de objetos e imágenes**.  
Cada actividad está enlazada desde un **index principal**, que permite acceder a cada práctica.

---

## 🧩 Actividad 1 – Identificar Imagen (MobileNet)
- Se creó una aplicación capaz de **reconocer objetos en imágenes cargadas por el usuario**.  
- Se utilizó el modelo **MobileNet** de ML5.js para clasificar imágenes y mostrar el **nombre del objeto y su porcentaje de confianza**.  
- Se añadió una **barra de progreso** que refleja visualmente el nivel de precisión.  
- Tecnologías: *HTML, Bootstrap, p5.js, ML5.js (MobileNet)*.

---

## 🔐 Actividad 2 – Login con Código por Dibujo (DoodleNet)
- Se implementó un **sistema de inicio de sesión con autenticación por dibujo**.  
- Cada usuario tiene un **código secreto** representado por un dibujo (por ejemplo: “sun”, “chair”).  
- Se utilizó el modelo **DoodleNet** para reconocer el dibujo y permitir el acceso solo si coincide con el código correcto.  
- Tecnologías: *HTML, CSS, p5.js, ML5.js (DoodleNet)*.

---

## 🗣️ Actividad 3 – Reconocimiento de Objetos con Voz (Teachable Machine)
- Se creó una aplicación que **detecta objetos en tiempo real mediante la cámara**.  
- Se entrenó un modelo personalizado con **Teachable Machine** y se integró con **ML5.js**.  
- Al detectar un objeto, el sistema **pronuncia su nombre mediante síntesis de voz**.  
- Se agregó una opción para **activar o desactivar el sonido**.  
- Tecnologías: *HTML, Bootstrap, p5.js, ML5.js, Teachable Machine, SpeechSynthesis*.

---

## 🏠 Index principal
El archivo **index.html** funciona como menú de navegación que permite acceder fácilmente a cada actividad:
- **Actividad 1:** Identificar Imagen  
- **Actividad 2:** Login con Código  
- **Actividad 3:** Teachable Machine
